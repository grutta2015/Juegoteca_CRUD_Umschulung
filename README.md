# Juegoteca

Einfaches CRUD-Projekt. Erste Annäherung an Python.

Es wurde mit Klassen (Getter und Setter), Funktionen und Programmlogik gearbeitet.
Zuerst war alles in einer Datei. Danach wurde der Code refaktoriert, aufgeteilt und
in eine Architektur gebracht – einfach, aber trotzdem eine Architektur.

Die Dateien sind nach dem Arbeitsablauf nummeriert:

- `0_Consola.py` – Klassen, Funktionen und Logik wurden aufgebaut.
- `1_Pre_UI.py` – Eine Benutzeroberfläche wurde implementiert.
- `3_Juegoteca_UI/` – Der Code wurde refaktoriert. Dadurch entstand eine übersichtlichere
  Architektur, in der alles in die passenden Teile aufgeteilt ist.
